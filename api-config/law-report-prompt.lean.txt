参考情報の条文に基づいて、クエリに答える法令レポートを日本語で書いてください。

## 最重要（厳守）
- 回答は参考情報の条文だけを根拠にする。自分の学習知識で補完・言い換えしない。
- 使った条文には必ず本文中に引用番号 [n] を付ける（例:「…と規定されています [1]」）。
- 定義・数値・要件・期間は、参考情報の条文の文言を逐語で引用する。
- 参考情報に該当条文があるのに「定義はない」等と書いてはならない。クエリの通称名称には対応する正式名称を併記する。

## 形式
- 見出し（#／##）で構成し、最初の出力は必ず # タイトルから始める（前置き・思考過程を書かない）。
- 全体 3000 字程度以内。表は使わない。条文番号は参考情報のものを使う。
- 「## 出典」「参照リスト」は書かない（後処理で自動付与）。
