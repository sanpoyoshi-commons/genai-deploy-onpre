# クラウド版（上流オリジナル源内）への乗り換え案内

本配布物（`genai-deploy-onpre`）は、**個人開発者がローカルで AI アプリ開発・実験を行う**ための、開発・実験用途・無保証の独立リポジトリです。**本番業務での利用や、実際の個人情報・機微なデータの取り扱いは想定していません**（免責の全文は [DISCLAIMER.md](../DISCLAIMER.md)）。

「実験ではなく、きちんとした用途で使いたい」「本番運用・組織導入を考えている」段階になったら、**本オンプレ配布物から離れ、上流のオリジナル（クラウド前提）構成へ乗り換える**ことを推奨します。本書はその案内です。

> **重要（非提携）**：本プロジェクトは上流（デジタル庁の `genai-ai-api` / `genai-web` 等）および同梱 OSS とは**無関係・非公式**です。乗り換え先は**上流の公式リポジトリ／公式の窓口**であり、本配布物に関する問い合わせを上流やデジタル庁へ行わないでください（窓口は本リポジトリ）。詳細は [DISCLAIMER.md](../DISCLAIMER.md)。

---

## いつ乗り換えるか（判断の目安）

本オンプレ配布物が**向かない**のは、おおむね次のような場合です。乗り換えを検討してください。

- **本番業務・組織導入**：可用性・サポート・SLA・コンプライアンスが要る。
- **実際の個人情報・機微データを扱う／法律・ルールへの対応が必要**：本配布物は想定外（無保証。[DISCLAIMER.md](../DISCLAIMER.md)）。
- **スケール／複数ユーザー運用**：本配布物は単一ホスト・個人 1 人を判断軸にしている。
- **公式のサポート・更新を受けたい**：本配布物はメンテナ 2 者体制の独立リポジトリ。

逆に、**ローカルでの開発・学習・PoC・小規模実験**であれば、本オンプレ配布物のままで十分です。

## 乗り換え先

上流オリジナルの源内（`genai-ai-api` / `genai-web`）は、**本来クラウド前提**で設計されています（クラウド向けの公式構成が用意されています）。本格運用は、本オンプレ配布物ではなく、**上流の公式リポジトリと公式デプロイ構成**に従ってください。

- **上流の公式リポジトリ**：デジタル庁の `genai-ai-api` / `genai-web`（公式の入手元・最新情報・サポート方針は上流に従う）。
- **公式のクラウド構成**：上流リポジトリにはクラウド向けのデプロイ構成（例：Azure 等）が含まれます。デプロイ手順・要件・サポートは**上流の公式ドキュメント**を参照してください。

> 本書は乗り換え先の存在と方針を案内するもので、**上流クラウドの具体的なデプロイ手順は上流の公式ドキュメントが正典**です。本配布物側でその手順を再掲・代行することはしません（非提携・誤認回避のため）。

## データの引き継ぎについて

本書は**乗り換え（用途の卒業）案内**であり、本オンプレ環境に蓄積したデータ（会話履歴・文書・法令 RAG 等）を上流クラウドへ自動移送する手順は提供しません。

- 本配布物のデータは、各 OSS（PostgreSQL／SeaweedFS 等）の標準機能でエクスポートできます（[docs/backup-restore.md](./backup-restore.md)）。
- ただし上流クラウド側のスキーマ・ストレージ・認証構成は本オンプレ構成と一致する保証がなく、**そのまま投入できるとは限りません**。移送が必要な場合は、上流の構成に合わせて各自の責任で行ってください（本配布物は無保証）。
